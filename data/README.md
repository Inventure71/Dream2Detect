# Data

This repository does not track the project data directory contents.

The code expects experiment data to be restored under `data/` from an external
archive supplied separately. Keep generated images, raw datasets, SQLite files,
caches, training runs, model checkpoints, QC sheets, manifests, registries, and
evaluation outputs out of normal Git commits.

When sharing the project, provide the data archive separately and extract it at
the repository root so the paths land under `data/`.
