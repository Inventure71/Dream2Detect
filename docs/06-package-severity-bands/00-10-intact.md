# Band 0-10: Intact

## Role In The Scale

This is the anchor band for visually intact packages.

If this band becomes loose, the whole scale drifts upward and `minor` loses meaning.

## Core Definition

This band should contain packages that look visually normal and undamaged.

The package may show negligible cosmetic noise, but no meaningful visible defect signal.

## Required Visual Characteristics

- box geometry remains clean and normal,
- no visible crushing,
- no visible collapse,
- no visible dent that changes the shape of a face,
- no clearly softened or damaged corner,
- no torn cardboard fibers,
- no tears,
- no holes,
- no openings,
- no bent or compromised flaps,
- no edge damage that attracts attention as a defect.

## Allowed Minor Traces

These may be present only if they are truly negligible:

- tiny dust,
- trivial print wear,
- tiny superficial specks,
- tiny handling traces that do not change the perceived condition.

These traces must not be the first thing a reviewer notices.

## Not Allowed In This Band

The image should be moved out of this band if any of the following are visible:

- a corner clearly looks softened or bent,
- a dent is visible as real shape change,
- a flap looks bent or imperfect in a defect-like way,
- a tear or fiber break is visible,
- the package face looks pushed in,
- a defect draws attention to one area as damaged.

## Visual Impression Test

A normal viewer should describe the package as:

- intact,
- normal,
- undamaged,
- fine,
- in good visible condition.

If the first honest reaction is "that corner may be damaged" or "there is something wrong there," it should not stay in this band.

## Prompt Guidance

Prompt for:

- clean cardboard shipping box,
- normal geometry,
- no visible damage,
- no meaningful dents, tears, crushing, or holes,
- only negligible handling wear if any.

Prompt wording should stay in the intact vocabulary:

- intact
- undamaged
- clean geometry
- negligible cosmetic wear only

Avoid prompting:

- softened corners,
- wrinkles that look like denting,
- visible creases,
- bent flaps,
- dramatic shadows that fake damage,
- any tear language,
- any opening language,
- any interior exposure,
- any collapse wording.

## Labeling Guidance

Assign `0-10` only when:

- the package is visually intact,
- any visible marks are trivial,
- there is no meaningful defect signal.

If you must argue for why something is still "basically fine," it probably belongs in `11-20` instead.
